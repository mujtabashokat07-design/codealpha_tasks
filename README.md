# CodeAlpha Data Science Tasks 💻📊

A collection of data science and machine learning tasks completed as part of my CodeAlpha internship experience.

This repository contains different beginner-to-intermediate machine learning exercises covering classification, regression, data analysis, and model visualization.

## Tasks Included

### 1. Iris Flower Classification 🌸

A machine learning classification project using the classic Iris dataset.

The project focuses on:

* Loading and exploring the dataset
* Feature analysis
* Data preprocessing
* Classification
* Model evaluation

Dataset:

```text
Iris.csv
```

### 2. Car Data Analysis 🚗

A machine learning project using car-related data to understand and predict car prices.

The project includes model analysis and visualizations such as:

* Actual vs predicted prices
* Feature importance

Dataset:

```text
car data.csv
```

### 3. Advertising Data Analysis 📢

A machine learning/data analysis task using advertising data to explore relationships between advertising channels and sales.

Dataset:

```text
Advertising.csv
```
